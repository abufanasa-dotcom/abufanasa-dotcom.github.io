2. Hosting über GitHub Pages

Die veröffentlichte Website wird über GitHub Pages ausgeliefert. GitHub verarbeitet bei der Nutzung seiner Dienste technische Daten, etwa IP-Adresse, Geräteinformationen und Zeitpunkt der Anfrage. Die Verarbeitung durch den Hostinganbieter wird in der GitHub-Datenschutzerklärung beschrieben; dort finden Sie auch Angaben zu internationalen Datenübermittlungen und Ihren Rechten gegenüber GitHub.

3. Funktionen dieser Website

Der Portfolio-Code setzt keine Cookies und lädt keine Analysedienste, externen Schriftarten oder eingebetteten Social-Media-Inhalte. Die ausdrücklich gewählte helle oder dunkle Darstellung wird ausschließlich auf Ihrem Gerät im lokalen Browserspeicher unter dem Schlüssel aa-portfolio-theme gespeichert. Gespeichert wird nur der Wert light oder dark; diese Einstellung wird nicht an einen Server übertragen. Ohne eigene Auswahl folgt die Darstellung der Systempräferenz. Bei gesperrtem Browserspeicher funktioniert der Wechsel für die aktuelle Seite. Bilder, Stylesheets und Skripte werden vom selben Website-Host geladen. Die Sprachwahl erfolgt über separate Seiten.

Die Kopierfunktion schreibt die angezeigte E-Mail-Adresse auf Ihren ausdrücklichen Klick in die Zwischenablage. Sie liest keine vorhandenen Inhalte der Zwischenablage aus.

4. E-Mail und externe Links

Ein E-Mail-Link öffnet Ihr eigenes E-Mail-Programm. Wenn Sie eine Nachricht senden, werden die mitgeteilten Angaben zur Bearbeitung Ihrer Anfrage verarbeitet. Dieses Portfolio enthält kein Kontaktformular. Die abschließenden Angaben zur Rechtsgrundlage, Aufbewahrung und zum verwendeten E-Mail-Dienst sind vor Veröffentlichung zu ergänzen.

Links zu LinkedIn, GitHub und dem Streamlit-Dashboard führen auf externe Websites. Erst wenn Sie diesen Links folgen, rufen Sie diese Dienste auf; dort gelten die jeweiligen Datenschutzhinweise.
