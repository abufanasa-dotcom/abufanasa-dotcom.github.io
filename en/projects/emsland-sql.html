Power generation · SQL data analysis / INDEPENDENT PROJECT

Analyzing Emsland generation data with SQL

Three published Emsland generation series for January 2025: how is recorded energy distributed across them?

Code & documentation ↗Download SQL code ↓

01 / MY CONTRIBUTION

Implementation

  • Built a relational SQLite schema with keys and a view for interval energy.
  • Developed nine SQL queries for coverage, aggregation, rankings, and time-series comparisons. The analysis was developed with AI assistance.

02 / METHODOLOGY

Data and approach

  1. 2,232 observations across 744 hours per series. The source uses Central European Time (CET), with timestamps also stored in UTC.
  2. Multiplying hourly average power in MW by the one-hour interval duration gives interval energy in MWh.
  3. LAG compares consecutive hourly averages within the same series. SQL energy totals were independently reconciled with the original values.

03 / RESULT

Results in context

D DT accounts for 79.48% of the recorded energy across the three selected series.

SCOPE

Scope and limitations.

Independent case study using SMARD data. Metrics describe the selected source series. A capacity factor would require verified, time-valid rated capacity. The data do not identify the operational causes of reported zero values.
